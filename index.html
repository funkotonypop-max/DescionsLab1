Analysis settings

Select which criteria to include in the staged decision process. Each criterion evaluates the alternatives differently.

03 / Decision flow

The selected criteria are applied one after another. Alternatives tied at a stage are kept for the next stage.

04 / Results

The best alternative under each selected criterion.

05 / Final recommendation

The result after applying your selected criteria in sequence.

How to read the results

A quick guide to the four decision rules.

Maximax
Find the maximum payoff in each row. Select the alternative with the largest of those values.
Maximin
Find the minimum payoff in each row. Select the alternative with the largest minimum.
Minimax Regret
For each state, subtract each payoff from the best payoff in that state. Select the alternative with the smallest maximum regret.
EMV / Bayes
Multiply each payoff by its state's probability and add the results. Select the highest expected value.
